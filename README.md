# Strumenti AILATI — pagina clienti

Pagina web del servizio Strumenti AILATI di AILATI SRL, pubblicata su
https://strumenti.ailatinetwork.com con GitHub Pages.

Contiene solo la grafica e i pulsanti: nessun dato, nessuna chiave, nessun file dei clienti.
Si entra con il link personale (la chiave sta dopo il `#`, quindi non arriva a nessun server)
e un codice inviato per email; tutto il resto lo fa lo sportello Apps Script di AILATI, che
controlla ogni chiamata.
